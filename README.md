# Hitayu

Website for Hitayu: organic herbal products, daily habits and yoga. Built with React and Vite.

## Run locally
```
npm install
npm run dev
```

## Edit content
Products, daily habits and yoga poses are plain lists at the top of `src/App.jsx`.
Replace `hello@hitayu.com` in the contact section with your real email.

## Deploy
Push to `main`. In the repo go to Settings, Pages, and set Source to "GitHub Actions".
The site will publish at `https://<your-username>.github.io/Hitayu/`.
If you use a custom domain or a different repo name, change `base` in `vite.config.js`.
